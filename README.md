# 3:4 Photo Collage

一个用于制作 **3:4 竖版拼图** 的轻量网页工具。

可以直接在电脑或手机上使用；当前交互主要针对 **Mac** 和 **iPhone / iPad** 做了优化。照片的读取、编辑和导出都在当前设备上完成。

## Features

- 固定 3:4 画布，导出尺寸为 **1800 × 2400 px**
- 提供 **2–6 格及 9 格**的多种预设布局
- 每个框可独立设置为 **图片** 或 **文字**
- 图片可移动、缩放和重置构图
- 规则网格支持调整行高和列宽
- 可调整外边距、框间距、圆角和背景色
- 文字支持字号、颜色、字重、字体选择和位置调整
- 支持批量选择图片，并可在预览中拖拽框来交换排列顺序
- 支持导出 PNG / JPG，文件名自动使用日期和时间
- 电脑端默认使用浏览器下载；在支持的浏览器中，也可选择并记住一个指定保存文件夹

## Privacy

选择的照片只会在当前设备上读取和处理。

本项目没有照片上传功能、服务器端图片处理、账号系统或云端存储。网页只会访问用户主动选择或拖入的图片，并在本机完成缩放、裁切、排版和导出。

## Usage

### Mac

1. 打开网页。
2. 点击选择图片，或直接从 Finder 将图片拖到目标框。
3. 在预览中调整构图，并根据需要修改布局、行列比例、间距、圆角、颜色或文字。
4. 批量导入后如需换顺序，点击“调整顺序”，再把一个框拖到另一个框上交换位置。
5. 点击“保存 PNG”或“保存 JPG”导出。默认由浏览器下载；支持文件夹授权的浏览器也可选择“指定文件夹”作为默认保存位置。

### iPhone / iPad

1. 打开网页，选择单张图片或使用“批量选择图片”。
2. 正常浏览时，单指上下滑动用于滚动页面。
3. 需要调整图片时，在对应框点“调整构图”；文字则点“调整位置”。
4. 进入图片调整模式后：
   - 单指移动图片
   - 双指缩放图片
5. 完成后点“完成调整”，再导出 PNG 或 JPG。
6. 如需调整排列顺序，点击“调整顺序”，再把一个框拖到另一个框上交换位置。
7. 导出后通过系统分享菜单保存到“照片”或“文件”。

大尺寸照片首次载入时会先在本机缩小到适合编辑的尺寸，因此可能短暂停顿；之后的编辑会更流畅。

> 当前版本主要在 macOS 和 iOS 上使用与调试；其他桌面或移动平台未做专门适配测试。指定文件夹保存依赖浏览器的 File System Access API，不支持时会自动回到普通浏览器下载。

## Fonts & Licenses

项目内置：

- **Cormorant** — 英文默认字体
- **ChillHuoFangKai_F（寒蝉活仿楷）** — 中文默认字体

两套字体均按 **SIL Open Font License 1.1** 分发。字体文件位于 `fonts/`，对应许可证位于 `licenses/`。

寒蝉活仿楷当前内置的是 Regular；选择 Medium / Semibold / Bold 时，部分浏览器可能使用合成字重。
