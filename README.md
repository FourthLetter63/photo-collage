# 封面排版 / Cover Layout

一个用于制作 **小红书 3:4 图文封面** 的本地网页工具。当前版本主要针对 **macOS** 和 **iPhone / iPad** 的使用方式进行设计和调试。

照片的读取、编辑和导出都在当前设备上完成。

## Features

- 固定 **3:4** 画布，导出尺寸为 **1800 × 2400 px**
- 提供 **1–6 格及 9 格**的多种预设布局
- 布局先按格数选择，再通过 **构图缩略图 + 名称**选择具体结构
- 每个框可独立设置为 **图片** 或 **文字**
- 图片可移动、缩放、重置构图；接近框中心时可自动吸附
- 规则网格可单独调整行高和列宽；其他布局可调整主区域比例
- 可调整外边距、框间距、圆角和背景色
- 支持批量选择图片；可在预览中拖动整个框来交换排列顺序
- 可添加多条 **叠加文字**，并分别调整位置、字号、颜色、字体、字重和阴影
- 框内文字和叠加文字都支持内置字体，也可输入本机已安装的字体名称
- 分别导出 **PNG** / **JPG**；文件名自动使用本地日期和时间
- Mac 上在支持的浏览器中会打开保存对话框，并记住上次保存位置；不支持时使用普通下载
- iPhone / iPad 优先使用系统分享菜单；不可用时退回浏览器下载

## Usage

### 1. 选择布局

先选择格数：

`1 / 2 / 3 / 4 / 5 / 6 / 9`

然后在下方选择对应的构图缩略图。布局名称包括：

`单图`、`上下`、`左右`、`上 1 + 下 2`、`上 2 + 下 1`、`左 1 + 右 2`、`左 2 + 右 1`、`三行`、`2 × 2`、`上 1 + 下 3`、`上 3 + 下 1`、`上 1 + 下 2 × 2`、`上 2 × 2 + 下 1`、`上 2 + 下 3`、`上 3 + 下 2`、`2 × 3`、`3 × 3`。

### 2. 添加内容

- 可使用“批量选择图片”，图片会按 **框 1 → 当前布局最后一个框**依次填入；超过当前框数的图片不会加入。
- 也可在每个框中单独选择图片。
- 每个框都可从“图片”切换为“文字”。
- Mac 上还可以直接从 Finder 将图片拖到目标框。

### 3. 调整图片或框内文字

**Mac：**

- 单击预览中的已有图片或框内文字进入调整模式。
- 图片可直接拖动；接近框中心时自动吸附。
- 图片进入调整模式后，可用鼠标滚轮、触控板双指滚动或缩放滑块调整大小。
- 也可以使用各框中的“调整构图 / 调整位置”按钮。

**iPhone / iPad：**

- 平时单指上下滑动用于滚动页面。
- 轻点已有图片或框内文字进入调整模式。
- 图片调整时：单指移动，双指缩放；接近框中心时自动吸附。
- 完成后点“完成调整”。

### 4. 调整顺序

点击“调整顺序”，再把一个框拖到另一个框上。交换的是**整个框内容**，包括图片或文字及其当前设置。

### 5. 叠加文字

叠加文字位于整个拼图上方，不占用任何框。每条文字可独立设置：

- 位置
- 字号
- 字体颜色
- 字体
- 字重
- 阴影颜色、透明度、模糊和偏移

叠加文字接近画布水平或垂直中心时会自动吸附。

### 6. 导出

点击“保存 PNG”或“保存 JPG”。

- 输出固定为 **1800 × 2400 px**
- JPG 质量为 **0.94**
- 文件名格式为本地时间 `YYYY-MM-DD_HH-MM-SS.ext`
- Mac：支持时打开保存对话框并记住上次位置；否则使用浏览器下载
- iPhone / iPad：优先打开系统分享菜单；不可用时使用浏览器下载

## Current behavior

- **当前不保存可继续编辑的工程。** 刷新或关闭页面会清空当前编辑状态，请先导出成品。
- 大尺寸照片载入时，如最长边超过 **4096 px**，会在本机生成较小的编辑副本，以降低拖动和缩放时的负担；不会修改原始照片。
- “自定义设备字体”依赖浏览器能否访问该设备上已安装的字体；不同系统和浏览器可能表现不同。
- 当前版本主要在 macOS 和 iOS 上使用与调试。

## Privacy

选择的照片只会在当前设备上读取和处理。

本项目没有照片上传功能、服务器端图片处理、账号系统或云端照片存储。网页只会访问用户主动选择或拖入的图片，并在本机完成缩放、裁切、排版和导出。

## Fonts & Licenses

界面使用：

- 中文字体：**匯文明朝體 v1.00**
- 英文字体：**Cormorant**

框内文字与叠加文字提供以下选项：

- **默认（Cormorant / 寒蝉活仿楷）**
- **匯文明朝體**
- **寒蝉活仿楷**
- **寒蝉活仿楷・窄体**
- **LXGW Bright**
- **Cormorant**
- **Corben**
- **Oleo Script Bold**
- **萌神拼音体**
- **芝士奶盖乌龙宋**
- **自定义设备字体**

实际内置字重：

- Cormorant：variable，300–700
- Corben：Regular / Bold
- LXGW Bright：Regular / Medium
- Oleo Script：Bold
- 芝士奶盖乌龙宋：Lite Bold
- 寒蝉活仿楷、寒蝉活仿楷・窄体、萌神拼音体、匯文明朝體：当前各内置一个常规字重

选择未内置的字重时，浏览器可能使用合成字重。

字体许可：

- Cormorant、Corben、Oleo Script、寒蝉活字系列、萌神拼音体、芝士奶盖乌龙宋、LXGW Bright：按各自的 **SIL Open Font License 1.1** 文件分发
- **匯文明朝體 v1.00**：按作者发布文章中的授权声明使用；该声明允许免费显示、嵌入、自由转发、随更大软件包分发，并允许用于开发新字体，但不可将字体文件单独作为商品转卖

字体文件位于 `fonts/`，对应许可或授权说明位于 `licenses/`。LXGW Bright 的 `OFL.txt` 保留官方原文；匯文明朝體的版本与授权来源记录在 `licenses/Huiwen-Mincho-License.txt`。
