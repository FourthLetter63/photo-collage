# 3:4 Photo Collage

一个用于制作 **3:4 竖版拼图** 的轻量网页工具。

可以直接在电脑或手机上使用；当前交互主要针对 **Mac** 和 **iPhone / iPad** 做了优化。照片的读取、编辑和导出都在当前设备上完成。

## Features

- 固定 3:4 画布，导出尺寸为 **1800 × 2400 px**
- 提供 **2–6 格及 9 格**的多种预设布局
- 每个框可独立设置为 **图片** 或 **文字**
- 可在整个拼图上方添加多条 **叠加文字**，并可设置阴影
- 图片可移动、缩放和重置构图
- 规则网格支持调整行高和列宽
- 可调整外边距、框间距、圆角和背景色
- 文字支持字号、颜色、字重、字体选择和位置调整
- 支持批量选择图片，并可在预览中拖拽框来交换排列顺序
- 支持导出 PNG / JPG，文件名自动使用日期和时间
- 电脑端默认使用浏览器下载；在支持的浏览器中，也可选择并记住一个指定保存文件夹

## Privacy

选择的照片只会在当前设备上读取和处理。

本项目没有照片上传功能、服务器端图片处理、账号系统或云端存储。网页只会访问用户主动选择或拖入的图片，并在本机完成缩放、裁切、排版和导出。

## Usage

### Mac

1. 打开网页。
2. 点击选择图片，或直接从 Finder 将图片拖到目标框。
3. 单击预览中的已有图片或框内文字即可进入调整模式；也可以使用对应框里的“调整构图 / 调整位置”按钮。
4. 图片进入调整模式后，可拖动位置，并用鼠标滚轮、触控板双指滚动或缩放滑块调整大小。
5. 批量导入后如需换顺序，点击“调整顺序”，再把一个框拖到另一个框上交换位置。
6. 如需在拼图上方加标题、日期等文字，使用“叠加文字”；每条文字可独立调整位置、字号、颜色、字体、字重和阴影。叠加文字默认使用暖白色 `#F5F2EA`。
7. 点击“保存 PNG”或“保存 JPG”导出。默认由浏览器下载；支持文件夹授权的浏览器也可选择“指定文件夹”作为默认保存位置。

### iPhone / iPad

1. 打开网页，选择单张图片或使用“批量选择图片”。
2. 正常浏览时，单指上下滑动用于滚动页面。
3. 轻点预览中的已有图片或框内文字即可进入调整模式；也可以使用对应框里的“调整构图 / 调整位置”按钮。
4. 进入图片调整模式后：
   - 单指移动图片
   - 双指缩放图片
5. 完成后点“完成调整”。
6. 如需调整排列顺序，点击“调整顺序”，再把一个框拖到另一个框上交换位置。
7. 如需在拼图上方加标题、日期等文字，使用“叠加文字”；每条文字可独立调整位置、字号、颜色、字体、字重和阴影。叠加文字默认使用暖白色 `#F5F2EA`。
8. 导出 PNG 或 JPG，并通过系统分享菜单保存到“照片”或“文件”。

大尺寸照片首次载入时会先在本机缩小到适合编辑的尺寸，因此可能短暂停顿；之后的编辑会更流畅。

> 当前版本主要在 macOS 和 iOS 上使用与调试。浏览器不支持指定文件夹保存时，会使用普通下载。

## Fonts & Licenses

项目内置以下已核实许可的开源字体：

- **Cormorant** — 英文默认字体
- **Corben** — Regular / Bold
- **Oleo Script** — Bold
- **ChillHuoFangKai_F（寒蝉活仿楷）** — 中文默认字体

以上字体均按 **SIL Open Font License 1.1** 分发。字体文件位于 `fonts/`，对应许可证位于 `licenses/`。

寒蝉活仿楷当前内置的是 Regular；选择 Medium / Semibold / Bold 时，部分浏览器可能使用合成字重。Corben 内置 Regular 与 Bold；Oleo Script 当前仅内置 Bold。
